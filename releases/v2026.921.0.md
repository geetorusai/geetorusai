# Geetorus v2026.921.0

Autonomous Agent Workforce Orchestration Engine — Production Release.

---

## Highlights

### 💓 Autonomous Pulse Engine
- Transitioned agent execution engine to the canonical **Pulse** paradigm.
- Added non-breaking `/pulse-runs/*` and `/companies/:companyId/pulse-runs` REST endpoints alongside legacy heartbeat routes.
- Exported typed `PulseRun`, `PulseRunEvent`, `PulseRunStatus`, and `PULSE_RUN_STATUSES` in `@geetorusai/shared`.
- Database migration `0280_pulse_runs_views.sql` introduces updatable PostgreSQL views (`pulse_runs`, `pulse_run_events`, `pulse_run_watchdog_decisions`) for zero-downtime schema evolution.

### 🛡️ Cross-Platform & Windows Execution Hardening
- Windows CLI spawn resolution with automatic `.cmd` and Git bash (`sh.exe`/`bash.exe`) fallbacks.
- Cross-platform sandbox path confinement normalizing Windows drive letters and forward slashes.
- Tar archive `--force-local` flag support for archive paths with colons.
- GNU coreutils backslash-immune sha256 checksum extraction across platforms.
- Atomic file replacement fallback on Windows `EPERM` locks in worktree port registries.

### 🐳 One-Click Docker Quickstart
- Root `docker-compose.yml` and `.env.docker.example` for zero-install container deployment.
- Embedded database initialization with automatic migration application on port 3100.

### 🛠️ Runtime Tool & Skill Studio
- Model Context Protocol (MCP) server injection directly into running agent sandboxes.
- Tool access policies, rate-limit counters, and dynamic capability provisioning without model retraining.

### 💰 Fiscal & Budget Governance
- Hard dollar and token spending limits per agent, project, and company boundary.
- Real-time spend telemetry and automated warning thresholds to prevent runaway API billing.
